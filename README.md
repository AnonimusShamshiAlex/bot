# deckbot

Телеграм-бот на Haskell, который делает презентации PowerPoint (.pptx).

Два режима:

- Автоматический. Пользователь пишет тему, выбирает число слайдов и оформление, а слайды пишет нейросеть. Нужен ключ Groq, OpenRouter или Anthropic.
- Ручной. Команда /new, название, тема, затем каждое сообщение это один слайд: первая строка заголовок, остальные пункты. Ключ не нужен.

Команды: /auto, /new, /done, /undo, /cancel, /help, /stats (для админов).
После автогенерации слайды можно дописывать вручную, удалять через /undo и снова получать файл через /done.

## Запуск на Windows

Запустите run.bat. Он поставит Haskell, если его нет, спросит токен бота, ваш Telegram ID и ключ нейросети (его можно пропустить), соберёт проект и запустит бота. Ответы сохраняются в token.txt, admins.txt и apikey.txt. Чтобы ввести их заново, удалите эти файлы.

## Запуск вручную

Нужны GHC 9.4 или новее и cabal. Запускать из папки проекта, потому что бот читает папку template.

    export BOT_TOKEN=токен_от_BotFather
    export BOT_ADMINS=123456789
    export AI_API_KEY=ключ_нейросети
    cabal run deckbot

Сервис определяется по началу ключа: gsk_ это Groq, sk-or- это OpenRouter, sk-ant- это Anthropic. Модель бот выбирает сам: при запуске он запрашивает у сервиса список доступных моделей, берёт подходящие (для OpenRouter только бесплатные) и при отказе пробует следующую. Необязательные переменные: AI_MODEL (принудительно задать модель, например meta-llama/llama-3.3-70b-instruct для платного OpenRouter) и BOT_AI_LIMIT (сколько автоматических презентаций доступно одному чату, по умолчанию 5; админам без ограничения).

## Устройство

- Bot.Types: диалог как конечный автомат на уровне типов. Стадия сессии и число слайдов входят в тип, поэтому собрать пустую презентацию или удалить слайд из пустой нельзя, код не скомпилируется. Число слайдов после автогенерации известно только во время работы, поэтому loadDeck упаковывает его в экзистенциальный тип.
- Bot.Logic: переходы диалога, лимиты и права. Команда /stats принимает только Actor 'Admin.
- Bot.Ai: запросы к Groq, OpenRouter и Anthropic и разбор ответа.
- Bot.Pptx: сборка .pptx без сторонних библиотек. Берёт шаблон из папки template, добавляет слайды и пишет zip.
- Bot.Api: тонкий клиент Bot API (long polling).
