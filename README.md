# deckbot

Телеграм-бот на Haskell, который собирает презентации PowerPoint (.pptx) из обычного текста.

Как пользоваться ботом: /new, название, тема (светлая, тёмная, синяя), затем каждое сообщение это один слайд. Первая строка заголовок, остальные строки пункты. Команда /done присылает файл. Дополнительно: /undo, /cancel, /help, /stats (для админов).

## Запуск на Windows

Запустите run.bat. Он поставит Haskell, если его нет, спросит токен и ваш Telegram ID, соберёт проект и запустит бота. Данные сохраняются в token.txt и admins.txt. Чтобы ввести их заново, удалите эти файлы.

## Запуск вручную

Нужны GHC 9.4 или новее и cabal. Запускать из папки проекта, потому что бот читает папку template.

    export BOT_TOKEN=токен_от_BotFather
    export BOT_ADMINS=123456789
    cabal run deckbot

При старте бот сам выставляет себе описание и меню команд.

## Устройство

- Bot.Types: диалог как конечный автомат на уровне типов. Стадия сессии и число слайдов входят в тип, поэтому собрать пустую презентацию или удалить слайд из пустой нельзя, код не скомпилируется.
- Bot.Logic: переходы диалога и права. Команда /stats принимает только Actor 'Admin.
- Bot.Pptx: сборка .pptx без сторонних библиотек. Берёт шаблон из папки template, добавляет слайды и пишет zip.
- Bot.Api: тонкий клиент Bot API (long polling).
